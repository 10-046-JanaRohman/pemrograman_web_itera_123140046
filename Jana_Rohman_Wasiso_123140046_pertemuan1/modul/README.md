# Latihan Modul JavaScript Dasar

File `latihan-javascript-dasar.js` memuat penyelesaian latihan mandiri dasar JavaScript:

- data diri dengan `const` dan `let`;
- pengecekan kelulusan, kategori umur, serta konversi hari;
- tabel perkalian, faktorial, bilangan prima, dan FizzBuzz.

Jalankan melalui konsol browser atau Node.js dengan perintah:

```bash
node latihan-javascript-dasar.js
```
